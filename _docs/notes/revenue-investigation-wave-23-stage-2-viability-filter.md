# Wave 23 Stage 2 — Viability Filter

## Evidence that changed scoring

- Freight invoice audit/payment is a mature category, including low-cost and contingency products aimed at small shippers.
- Accessorial leakage is also actively served on the broker/3PL side, but current operational guidance repeatedly shows a carrier-side documentation problem: detention and other accessorials are lost when times, notices, receipts or rate-confirmation terms are missing at billing time.
- POD software is mature, so another delivery-capture app is unattractive. A narrower pre-billing evidence check remains more plausible.
- Supplier-price-file and pack-size comparison tools now have several exact current products, so generic supplier-price diffing is crowded.
- Wholesale pack-size/UOM errors remain operationally expensive because case, inner-pack and each-level quantities can be represented inconsistently across purchasing, ERP and customer orders.
- Distributor rebate/SPA recovery is already a current specialist market, reducing appeal for generic rebate audits.
