# Wave 25 Stage 2 — Viability Filter

## Evidence that changed scoring

- Credential expiry/compliance is already a standard staffing-platform feature, including assignment blocking for expired credentials.
- Client document collection is crowded across accounting/legal/professional-services firms, including lightweight specialist products.
- Professional-services guidance continues to emphasize formal scope/change controls because undocumented extra work creates fee, schedule and liability risk. This keeps scope-leakage auditing commercially relevant.
- Staffing platforms already cover onboarding/checklists broadly, so the better wedge is independent reconciliation between a client's assignment requirements, a worker's evidence and the actual placement record.
- Timesheet/invoice automation is mature, but independent checks for approved hours/rates versus billed hours can still be valuable where staffing firms use disconnected ATS, payroll and accounting systems.
