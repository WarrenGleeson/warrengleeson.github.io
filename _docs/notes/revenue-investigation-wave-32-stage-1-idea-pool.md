# Revenue Investigation — Wave 32 Stage 1 Idea Pool

## Platform thesis
GitHub Marketplace supports paid GitHub Apps with GitHub-hosted billing. GitHub retains 5% of post-2021 Marketplace revenue. Paid plans require verified-publisher status and, for GitHub Apps, at least 100 installations before paid publishing. That favors useful free-first utilities with a natural paid tier.

## Constraint
Generate 60 GitHub App ideas with repository/org-level value. Avoid generic CI, code review, vulnerability scanning, dependency update bots, release automation, issue/project management and secrets scanning. Prefer read-only or low-risk change-preflight utilities. Stop at Stage 4 planning.
