# Profile Conversion

## Objective

Increase the percentage of people who visit the EirePolitic profile and choose to follow.

## Questions to answer

- Is the profile proposition immediately clear to a first-time visitor?
- Does the bio explain what EirePolitic provides and why following is useful?
- Are profile image, name field, category, links, and pinned posts optimised for discovery and trust?
- Do pinned posts explain the account quickly?
- Is there a clear path from a high-performing post to deeper profile exploration?

## Evidence to inspect

- Current live Instagram profile.
- Current bio, name field, links, pinned posts, and Highlights.
- Account-level profile visit and follow data.
- Public website landing pages linked from Instagram.

## Investigation tasks

- [ ] Capture current profile configuration.
- [ ] Review first-visit clarity.
- [ ] Review search keyword coverage in profile name/bio.
- [ ] Review pinned-post strategy.
- [ ] Review link destination and friction.
- [ ] Define one or more profile-conversion experiments.

## Candidate experiments

- Existing bio vs clearer value proposition.
- Different pinned-post combinations.
- “What EirePolitic is” explainer as a pinned carousel.
- Topic navigation or “start here” post.
- Different profile-link landing page.

## Success criteria

Primary:
- follows per profile visit;
- profile visits per 1,000 non-follower accounts reached.

Secondary:
- profile-link clicks;
- engagement with pinned content.

## Risks / safeguards

Avoid language that suggests endorsement, activism, campaigning, or partisan alignment.

## Questions for the user

Ask only where live profile access is unavailable or ambiguous.

## Handoff instructions for future LLM chats

Inspect the current profile before drafting recommendations. Keep proposed changes factual, neutral, and reversible. Prefer one controlled profile change at a time where measurement allows.
