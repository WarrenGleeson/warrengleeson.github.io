# Sharing, Saves, and Reposts

## Objective

Increase organic distribution by making posts practically useful to viewers and other accounts.

## Core hypothesis

For a factual political-information account, utility and reference value are more credible growth mechanisms than controversy.

## Questions to answer

- Which current formats naturally deserve saving?
- Which posts can be useful to journalists, students, civic groups, or politically interested users?
- What makes a post safe for another neutral account to repost?
- Can templates explicitly optimise for self-contained usefulness?

## Candidate formats

- concise explainers;
- reference charts;
- stage/timeline graphics;
- constituency facts;
- “what changed” summaries;
- glossary cards;
- bill summaries with plain-language context.

## Investigation tasks

- [ ] Identify high-save candidate formats.
- [ ] Identify high-share candidate formats.
- [ ] Define “self-contained repostable post” design rules.
- [ ] Test subtle utility CTAs.
- [ ] Measure downstream profile visits/follows from high-share posts.

## Success criteria

- shares per 1,000 reached;
- saves per 1,000 reached;
- non-follower reach;
- follows per 1,000 reached.

## Risks / safeguards

Avoid designing for outrage or partisan in-group sharing.

## Handoff instructions for future LLM chats

Evaluate utility first. Recommend repost/share-oriented formats only where the informational value is genuine.
