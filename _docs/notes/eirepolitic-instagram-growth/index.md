# EirePolitic Instagram Audience-Growth Programme

## Purpose

This programme defines a practical, experiment-driven plan for increasing EirePolitic's Instagram reach, discovery, followers, and repeat engagement while preserving political neutrality, factual accuracy, and low manual workload.

The programme is intentionally documentation-first. It is designed so that future LLM chats can take one workstream at a time, inspect the relevant repositories and systems, gather missing evidence, and guide implementation without needing to reconstruct the strategy from scratch.

## Core constraints

Prioritise:
1. No-cost methods.
2. Very low-cost methods.
3. Low manual-work methods.
4. Methods that can be automated or systematised.
5. Higher-effort methods only where expected return justifies them.

Do not assume ongoing manual activity such as daily commenting, large-scale DMs, constant trend research, or bespoke daily content creation.

Do not weaken EirePolitic's neutrality, sourcing standards, or care around parliamentary inference.

Do not modify production publishing schedules, AWS infrastructure, Instagram publishing configuration, or other runtime systems without explicit approval.

## Current diagnosis

EirePolitic already has a scalable structured-content production system. The likely growth bottlenecks are:

- weak discovery packaging relative to the underlying informational value;
- limited measurement of post-level acquisition performance;
- limited systematic testing of hooks, covers, formats, timing, and calls to action;
- underuse of low-effort repurposing into discovery-oriented formats;
- limited structured distribution outside the existing follower base.

## Primary optimisation metrics

Treat these as the main growth metrics where data is available:

- non-follower reach;
- profile visits;
- follows per 1,000 accounts reached;
- shares;
- saves;
- engagement from non-followers;
- Reel watch-through / retention;
- carousel depth / completion where measurable;
- repeat viewers;
- follower growth over time.

Do not optimise primarily for likes.

## Recommended order

Start with measurement, discovery packaging, and profile conversion. Those three areas create the feedback loop needed to evaluate the remaining workstreams.

Then investigate low-effort distribution expansion through Reels/repurposing, shares/reposts, topical formats, caption/search optimisation, collaborations, and external traffic.

The 30/60/90-day plan should be updated as evidence accumulates rather than fixed in advance.

## How future LLM chats should use this programme

Before proposing implementation in any workstream:

1. Read this page and the relevant workstream page.
2. Inspect the current repository documentation and live configuration relevant to that workstream.
3. Prefer repository documentation as the source of truth.
4. Verify current platform behaviour where Instagram or Meta features may have changed.
5. Identify missing information that materially affects the plan.
6. Ask the user only for information that cannot be obtained from connected systems or public sources.
7. Separate investigation, recommendation, and implementation.
8. Do not change production systems without explicit approval.
9. Record conclusions, rejected options, dependencies, and next actions back into the relevant workstream page.
