# Cross-Platform and External Traffic

## Objective

Create low-maintenance external discovery paths that reinforce Instagram growth.

## Questions to answer

- How prominently does the public EirePolitic site surface Instagram?
- Can website pages embed or link to relevant Instagram content?
- Which structured posts can be republished automatically to other platforms?
- Can GitHub Pages documentation/public pages support search traffic into EirePolitic content?
- Which channels add meaningful reach without multiplying maintenance work?

## Candidate channels

- public website;
- Bluesky/X where appropriate;
- LinkedIn for policy/data-oriented posts;
- Threads;
- newsletters or RSS if eventually available;
- embedded social links in public data/explainer pages.

## Investigation tasks

- [ ] Audit website-to-Instagram paths.
- [ ] Audit existing social account presence.
- [ ] Identify formats that can be cross-posted automatically.
- [ ] Define canonical source and deduplication rules.
- [ ] Estimate ongoing maintenance per channel.
- [ ] Test one low-effort external source at a time.

## Success criteria

- referral traffic;
- profile visits;
- follower growth attributable to external campaigns;
- zero or minimal additional manual publishing effort.

## Risks / safeguards

Do not create a multi-platform maintenance burden that exceeds the value of the traffic generated.

## Handoff instructions for future LLM chats

Inspect current public-site structure and existing social integrations before proposing new channels. Prefer reuse and syndication over bespoke content.
