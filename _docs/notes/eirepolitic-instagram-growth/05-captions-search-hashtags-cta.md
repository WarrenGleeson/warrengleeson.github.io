# Captions, Search, Hashtags, and Calls to Action

## Objective

Improve discoverability and viewer action using low-cost text-layer changes that can be templated and automated.

## Questions to answer

- How descriptive are current first caption lines?
- Which keywords should be expressed naturally for Instagram search?
- Which hashtags are useful and specific enough to retain?
- Which CTAs increase saves, shares, follows, or profile exploration without engagement bait?
- How much caption length is necessary for each content family?

## Evidence to inspect

- Existing caption templates.
- Hashtag defaults.
- Search-visible account/profile text.
- Performance data by caption variant when available.
- Current Meta guidance on hashtags/search.

## Candidate experiments

- short vs long caption;
- source-first vs summary-first;
- question CTA vs utility CTA;
- “save for reference” where genuinely useful;
- “follow for…” proposition on selected acquisition posts;
- topic-specific keyword variations.

## Success criteria

- shares;
- saves;
- profile visits;
- follows per 1,000 reached;
- search-originated reach if available.

## Risks / safeguards

Do not use manipulative engagement bait or spammy hashtag strategies.

## Handoff instructions for future LLM chats

Inspect current templates first. Prefer changes that can be expressed as reusable rules rather than one-off caption writing.
