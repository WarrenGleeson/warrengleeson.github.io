# Topical and Evergreen Content

## Objective

Use EirePolitic's structured data to create a balanced mix of timely discovery content and evergreen educational posts.

## Questions to answer

- Which data products can react to current political events without manual research?
- Which parliamentary concepts repeatedly confuse general audiences?
- Which evergreen posts can be reused or resurfaced?
- How can topical relevance be detected automatically?
- What proportion of the feed should be topical vs procedural vs evergreen?

## Candidate topical formats

- “What this bill does” when legislation enters a meaningful stage;
- “What changed?” around a current poll or parliamentary event;
- representative/party facts tied to a current story;
- neutral issue timelines.

## Candidate evergreen formats

- how a bill becomes law;
- what Dáil stages mean;
- how committees work;
- who represents whom;
- how to read a division;
- what specific Oireachtas terms mean.

## Investigation tasks

- [ ] Catalogue data sources suitable for topical triggers.
- [ ] Catalogue high-value evergreen explainers.
- [ ] Define neutral topical-trigger rules.
- [ ] Define reuse/resurfacing rules.
- [ ] Define freshness and sourcing requirements.

## Success criteria

Compare:
- non-follower reach;
- shares;
- saves;
- follows per 1,000 reached;
- long-tail reach after publication.

## Risks / safeguards

Do not infer political significance beyond the source record. Clearly distinguish descriptive event context from analysis.

## Handoff instructions for future LLM chats

Use current-event web research where needed, but keep the underlying post grounded in source data and neutral factual framing.
