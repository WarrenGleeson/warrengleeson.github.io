# Discovery Hooks and Carousel Packaging

## Objective

Make EirePolitic's structured political information understandable and compelling to people who do not already know parliamentary terminology or the account.

## Core hypothesis

The underlying information is useful, but many current covers describe the dataset or parliamentary category rather than the reason a general viewer should continue.

## Questions to answer

- Which current cover patterns underperform?
- Which content families have the strongest latent general-interest angle?
- How can formal titles and procedural accuracy be preserved while simplifying the first slide?
- What carousel depth is effective?
- What visual hierarchy best communicates “why this matters” without sensationalism?

## Evidence to inspect

- Current Bill Tracker covers and carousels.
- Party profile/speech breakdown visuals.
- Polling graphics.
- Any future structured-content templates.
- Performance metrics once available.

## Candidate experiment families

- Question headline vs factual headline.
- “What changed?” framing vs procedural-stage framing.
- Plain-language hook vs formal title.
- One subject per carousel vs multi-item roundup.
- Shorter vs longer carousel.
- Cover with key number vs cover without key number.
- General-audience explainer slide before formal detail.

## Success criteria

Primary:
- non-follower reach;
- follows per 1,000 accounts reached;
- shares;
- saves.

Secondary:
- carousel depth/completion if measurable;
- profile visits.

## Investigation tasks

- [ ] Catalogue current cover patterns.
- [ ] Define safe hook-writing rules.
- [ ] Define a small set of reusable hook archetypes.
- [ ] Select 2-3 content families for controlled tests.
- [ ] Define visual variants.
- [ ] Define metadata needed to label experiment variants automatically.

## Risks / safeguards

Do not:
- imply policy effects not supported by the source;
- exaggerate the significance of procedural events;
- use rage-bait, partisan framing, or manufactured controversy;
- oversimplify formal legal status.

## Handoff instructions for future LLM chats

Read the source content and formal parliamentary semantics before proposing hooks. Keep slide 1 accessible, while using later slides for precision and caveats. Record each tested hook variant as structured experiment metadata.
