# Reels and Content Repurposing

## Objective

Expand non-follower discovery using short-form video without requiring regular filming, voiceover, or bespoke manual editing.

## Core hypothesis

Existing structured data, charts, headlines, and carousels can be transformed automatically into short vertical sequences.

## Questions to answer

- Which existing content types are easiest to repurpose?
- Can current renderers produce 9:16 assets?
- Is text-only / chart-led motion sufficient?
- Which Reel lengths are practical?
- Can Trial Reels be used for low-risk discovery testing?
- What metadata is needed to compare Reel vs carousel performance?

## Candidate formats

- hook → key fact → context → source/CTA;
- animated chart reveal;
- “3 things to know” sequence;
- bill-stage explainer;
- before/after polling movement;
- constituency or representative fact card sequence.

## Investigation tasks

- [ ] Audit current rendering stack for vertical output.
- [ ] Identify reusable assets.
- [ ] Define 2-3 minimal Reel templates.
- [ ] Determine audio requirements and rights constraints.
- [ ] Assess Meta publishing/API support for the current pipeline.
- [ ] Define Trial Reel test plan if available.
- [ ] Define comparison metrics against static/carousel posts.

## Success criteria

- non-follower reach relative to carousel baseline;
- follows per 1,000 reached;
- shares;
- average watch time / completion;
- low incremental manual effort.

## Risks / safeguards

Avoid trend-chasing that creates recurring manual workload. Do not use copyrighted audio unless the publishing method and account rights clearly permit it.

## Handoff instructions for future LLM chats

Inspect current Instagram renderer and publishing support before choosing a technical approach. Prefer the smallest reusable format that can be automated from existing data.
